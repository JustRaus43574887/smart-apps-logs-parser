# Express Log Parser

Веб-приложение для удобного просмотра и анализа логов в формате JSONL (JSON Lines). Позволяет загружать лог-файлы, фильтровать записи по типам и искать совпадения по всему контенту.

## Возможности

- 📁 **Загрузка JSONL и ZIP** — `.jsonl`, `.json`, `.txt`, а также `.zip` с логами внутри
- 🖼️ **Screenshot** — если в ZIP есть изображение (jpeg/png/gif/webp/bmp), доступна кнопка просмотра на весь экран
- 🔍 **Поиск** — по всем полям логов, включая ключи и значения в `payload`; жёлтая иконка (!) указывает на совпадение только в скрытых полях
- 🔐 **Два режима поиска** — нестрогий (частичное совпадение) и строгий (точное совпадение значения поля)
- 🏷️ **Фильтрация по типам** — фильтруйте логи по типам событий:
  - Device Info
  - REST Event
  - WebSocket Event
  - Browser Log
  - SmartApp Event
  - Client Log
  - Client State

### Требования
- Node.js 16+
- npm или yarn
